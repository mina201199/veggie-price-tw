# 菜市漫遊：手機 3D 原型

## 私人採買筆記（本機版）

城市左側「採買筆記」或 `notebook.html` 可直接使用，不必進行 3D 探索。支援商品、品牌、分店／攤位、規格、日期、價格、重量、促銷、私人心得、搜尋、再次購買、修訂歷史與 JSON 備份匯出。按重量換算公斤價，不推測每顆／每包的重量。

資料存於同一來源瀏覽器的 localStorage `veggie-shopping-notes-v1`，不是登入帳號、加密保險箱或雲端同步；共用裝置可被他人看到。清除瀏覽器資料會遺失，應定期匯出。localhost 與 127.0.0.1 是不同來源，資料不共用。儲存失敗不顯示成功，讀取毀損資料時停止寫入，可匯出原始內容。編輯會保留舊版私人內容於歷史中；目前沒有刪除／匯入復原介面。

「願意分享價格」目前只記本機意願，並展示白名單欄位，不上傳、不送審、不核發點數。未來正式串接必須重新確認授權，不能自動送出既有筆記。照片與 LLM 尚未接入。執行 `node prototype-3d/notes.test.cjs` 驗證儲存、修訂、隱私與單位規則。

從專案根目錄執行 `python -m http.server 8877 --bind 127.0.0.1 --directory prototype-3d`，開啟 http://localhost:8877。

拖曳搖桿或使用 WASD／方向鍵走動；拖曳場景、旋轉按鈕調整鏡頭。「往入口走」示範前往市場。抵達入口後才能進入，市場使用攤位層級，其他通路使用分店品類層級。碰撞阻擋穿入建築。

角色、建築、樹木與攤棚為原創程序化幾何模型；使用固定版本 Three.js 0.160.1（MIT，vendor/three.min.js）。可離線載入，不需 CDN 或外部帳號。

抵達後進入可行走的 3D 室內：市場有攤棚、攤商和商品；連鎖分店有貨架和生鮮檯。走近金色圓圈即可看商品、收集品項卡或模擬送審。卡片及待審狀態保留於這次頁面工作階段，刷新即重置，沒有實際點數交易。「帶我逛攤位」示範沿走道前往下一站；出口或「返回城市」可離開。

「換角色」提供五款原創程序化造型：小小探險家、草莓兔兔、蜂蜜熊熊、奶茶貓貓、青蛙雨衣。衣櫥支援正背面 3D 預覽、步行試穿，並同步替換城內和室內角色。造型偏好以 `veggie-avatar-v1` 存在本機 localStorage；不傳送至外部服務，儲存不可用時仍能換装。

衣櫥裡的兩隻貓「歐巴」「波妞」使用 `cat-kit.js` 的毛皮模型（與 cats-demo.html 同一套），`cats.js` 只負責包裝：城內用四腳步態走路，停下約 4 秒會坐下，頭會轉向鏡頭；衣櫥預覽另建一隻，可以試走。毛皮在城內透過只寫入陰影圖的替身網格投影。執行 `node prototype-3d/cats.test.cjs` 驗證尺寸、站地與轉頭。

此為手機比例的瀏覽器原型，不是已打包的 Android/iOS App。街區與室內皆為原創示意，並非真實店面還原；距離、價格、點數皆為示意。尚未整合 GPS、真實地圖、照片、AI 驗證、多人資料庫、訂閱或點數交易。照片位置保留為明確佔位，沒有偽裝成真實攤位照片。

## 貓咪帶路（cats-demo.html）

開啟 http://localhost:8877/cats-demo.html。黑貓烏咪與 Mochi 依參考圖重新建模：大頭短腿的幼貓比例、shell 著色的毛皮（`cat-kit.js`），會眨眼、抖耳朵、甩尾巴，有站、走、坐、翻肚四種姿勢。拖曳轉鏡頭，雙指或滾輪縮放；搖桿、WASD 或點地面讓貓走過去。走到菜籃旁會顯示這菜貴不貴的判斷；價格是 `site/data.json` 2026-09-30 的批發價快照，寫在 `cats-demo.js` 裡，尚未接即時資料。

`CatKit.create(THREE, 'blackcat' | 'mochi', { shells, castShadow })` 回傳 `{ root, setState, update, meow }`，可以直接放進其他 Three.js 場景；`update(dt, { speed, look })` 的 look 是世界座標，貓放在別的物件裡也能正確轉頭。`node cat-kit.test.cjs` 檢查兩隻貓在每個姿勢都站在地面上。手機預設 12 層毛、電腦 20 層，畫面太慢時會自動降解析度。
