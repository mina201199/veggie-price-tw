# 今日菜價（本機手機頁面）

入口：`prices.html`（本機 app 的首頁）。上方是貓咪帶路的 3D 場景（`cat-guide.js`），下方抽屜是這份菜價清單（`prices-ui.js`）；不需要登入。

使用既有 `data/raw/*.json` 中農業部資料，每個「種類／作物代號／完整官方品名」獨立呈現。
常用名、分類（含辛香）、不收的品項（醃漬加工品、「其他」類）與往年同期規則，跟公開網站共用 `tools/catalog.py`；
快照由 `tools/build_prices.py` 產生，瀏覽器端（`prices-core.js`）只負責判斷標籤、搜尋與排序。
此來源已彙整全臺市場，無法提供個別市場比較，也無法保證每天參與市場集合完全相同。

## 攤販賣多少

菜價詳情裡可以輸入攤販開的價格和重量（台斤、公斤或公克），換成元／台斤後跟「一般零售範圍」比：低於範圍是划算，範圍內是合理，高出範圍 20% 以內是偏貴，再高是太貴，門檻與公開網站相同（`Prices.judgeStall`）。
一般零售範圍由 `tools/build.py` 的 `retail_estimate` 算好放在快照的 `retail`（以常用名為鍵，所有品種合計），公開網站也讀同一份數字：依臺北市公有零售市場 2024/7–2025/12 的月均零售價（元／台斤）對照同月批發價，求出「零售 ≈ a + b × 批發」，再套用近 14 天批發均價。臺北市沒有的品項，進口品借用國產同品項、其他用同類平均倍數估計，範圍放寬。只在瀏覽器裡計算，不會送出輸入的價格。

## 分析限制

顯示最後交易日的全臺交易量加權均價，不使用平滑價格冒充當日價格。
以該交易日往前五年各年同日期 ±15 天的每日均價中位數比較；至少 20 個日紀錄、2 年才給結論（公開網站同一規則）。
正負 12% 內為接近常態，外側為偏高／偏低。超過 7 天未更新不給當前判斷。
近期比較為最後交易日前七日的交易量加權均價，不含最後交易日。
曲線只繪出已觀測日期；空缺不補零、不推估。
未串 LLM、帳號或定位；零售部分只有上面「攤販賣多少」的範圍估計，不預測未來價格。所有文字解釋都基於可查數值。
